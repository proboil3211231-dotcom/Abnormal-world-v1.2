FORGEBLOCK LEGENDS — WORLD UPDATE 2

Included:
- New generated ancient ruins and glowing portal gateways.
- Portal travel: walk close to a portal and press E (or the Talk button).
- Region-based vibrant biome colour palettes.
- Organic tree silhouettes with rounded, varied leaf clusters and textured trunks.
- Four village house styles with varied walls, roofs, windows and chimneys.
- More visible villagers with human-shaped proportions, faces, hair and clothing colours.
- Reduced distance fog and a larger sky dome.
- Hostile mobs can remain and spawn during daytime; they no longer despawn just because it is day.
- More forgiving hit detection for aiming at mobs.
- Custom drawn SVG-style action buttons instead of emoji symbols.

INSTALL:
1. Extract this ZIP.
2. Replace the old game's files with all files from this folder.
3. Keep index.html, manifest.json, sw.js, icon-192.png and icon-512.png together.
4. If using GitHub Pages, upload/commit all files and refresh the website. If an old version remains cached, clear the browser site cache or use a new query string such as ?v=2.

NOTES:
- The game uses Three.js from a CDN, so an internet connection is required when loading it.
- Google sign-in and online friend PvP still require your own Firebase web-app configuration and Realtime Database setup in the Online tab.
- Procedural world features are generated as you explore; the world is not a hand-authored fixed map.
- The game code passed a JavaScript syntax check. This is not a guarantee of zero runtime bugs; test the new build on your target phone/browser.
